### Auto-fixed Issues

**1. [Rule 1 - Bug] AtfScopeChip.label não casava com find.text(label) exato**
- **Found during:** Task 3 (unificação do branch desktop de `PiquetesScreen`)
- **Issue:** Antes desta task, a aba Piquetes em >=1024px ainda caía no layout mobile (`isDesktop && _showLots`), então `AtfScopeChip` só aparecia depois de trocar para a aba Lotes — e o teste pré-existente `test/widget/lotes_desktop_test.dart` alcançava essa troca tocando o `_SegmentButton` mobile (dois `Text` separados, casava com `find.text('Lotes')` exato). Ao unificar o branch para as duas abas mostrarem UI desktop imediatamente, `PiquetesLotesHeader`/`AtfScopeChip` passou a ser o primeiro widget renderido — mas `AtfScopeChip.label` usava `Text.rich(TextSpan([label, ' $count']))`, cujo texto flatten é `"Lotes 2"`, não `"Lotes"`. `find.widgetWithText(InkWell, 'Lotes')` (usado por `lotes_desktop_test.dart`, arquivo intocável) parava de encontrar o widget.
- **Fix:** `AtfScopeChip.label` trocado de `Text.rich(TextSpan(...))` para `Row(children: [Text(label, ...), Text(' $count', ...)])` — mesmo estilo, mesmo resultado visual, mas agora `label` existe como `Text` exato-casável isoladamente.
