<objective>
Layout mestre-detalhe desktop na tela de Reprodução: a partir de `Breakpoints.rail` a
lista de ATFs vira uma tabela de ciclos e selecionar uma linha abre um painel lateral de
380px com o resumo do ciclo, de onde "Continuar DGs" leva ao detalhe do ATF existente.

Purpose: em desktop a lista de cards desperdiça a largura e obriga um round-trip
(lista -> detalhe -> voltar) para conferir cada ciclo. O fluxo real do veterinário é
varrer os ciclos abertos e mergulhar nos DGs pendentes.
Output: `ReproducaoTableView` + `AtfDetailPanel`, `ReproducaoScreen` decidindo a forma via
`LayoutBuilder`, e teste de widget cobrindo os dois lados do corte.
</objective>
