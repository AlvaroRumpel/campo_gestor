## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Flutter role gate → RLS write policies | Hidden edit and archive controls are convenience; the policies are the guard |
| Route query parameters → filter state | An arbitrary lote or animal id can be typed into the URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04 | Elevation of Privilege | dose edit or archive by a non-veterinarian | high | mitigate | Controls omitted from the tree for other roles, and `veterinarian_can_update_active_dose` rejects the write server-side regardless of how it is issued |
| T-06-06 | Information Disclosure | a seeded filter id from another property surfacing data | high | mitigate | Filters run over a list already scoped by the SELECT policy and by the active property, so a foreign id simply matches nothing |
| T-06-15 | Information Disclosure | a voided application presented as still in effect | medium | mitigate | `visibleApplications` hides reversed originals and reversal records by default; when shown they carry a strikethrough and a badge |
| T-06-12 | Tampering | a fabricated price shown for a dose or application with no cost | medium | mitigate | Every cost segment on both tabs is inside a null check on the frozen or stored cost field |

ASVS level 1; blocking severity is high. No new packages, so no supply-chain row.
</threat_model>
