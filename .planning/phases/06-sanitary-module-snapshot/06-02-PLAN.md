## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → SECURITY DEFINER RPC | Caller controls lot id, dose id, date, animal id list and free-text notes/reason |
| authenticated client → PostgREST table endpoints | Direct reads and writes that never enter the RPCs |
| `doses` row → frozen application row | Values copied across a trust boundary in time — a later dose edit must not rewrite history |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-06-01 | Tampering | `sanitary_applications` frozen row | high | mitigate | Phase 2's `trg_snapshot_immutable` left intact by ALTER-only extension; exactly one SELECT policy, zero write policies, so no PostgREST mutation path exists |
| T-06-02 | Tampering | client-submitted totals | high | mitigate | `register_sanitary_application` derives every numeric column from `animals`, `doses` and `properties.kg_per_ua`; no total is a function parameter |
