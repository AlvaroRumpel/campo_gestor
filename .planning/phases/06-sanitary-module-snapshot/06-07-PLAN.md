## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client preview totals → frozen server totals | The previewed figures are display-only; the RPC recomputes independently |
| Double tap / concurrent confirm → duplicate frozen rows | An immutable row cannot be un-written |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-02 | Tampering | client-computed totals reaching the frozen row | high | mitigate | The register call's argument list contains no total; the RPC signature has no parameter to receive one, so the preview is structurally incapable of influencing what is stored |
| T-06-03 | Tampering | stale composition confirmed after the lot changed | high | mitigate | The RPC aborts with P0002; the mapped reason renders the server's own sentence and the recovery action returns a reload outcome that re-fetches while preserving deselections |
| T-06-13 | Tampering | double submission producing two frozen rows | medium | mitigate | Confirm and back are both disabled for the duration of the in-flight call, and the duplicate-detection gate additionally requires an explicit acknowledgement when the same dose/lote/date already exists |
| T-06-04 | Elevation of Privilege | registration attempted by a non-veterinarian | high | mitigate | Reachable only behind role-gated entry points, and the RPC raises 42501 which maps to the locked refusal copy rendered inline |

ASVS level 1; blocking severity is high. No new packages, so no supply-chain row.
