    Methods, all against the `doses` table endpoint — no RPC, because dose writes are single-row and
    fully covered by the policies created in 06-02:
    `fetchDosesByProperty(String propertyId, {bool includeArchived = false})` selecting all columns,
    filtering `property_id`, applying the `deleted_at` null filter only when `includeArchived` is
    false, ordered by `name`;
    `fetchDose(String id)` returning a nullable `Dose` via `maybeSingle`;
    `createDose({required String propertyId, required String name, String? activeIngredient,
    required double dosagePerKg, double? costPerKg})` inserting and returning the created row;
    `updateDose({required String id, required String name, String? activeIngredient,
    required double dosagePerKg, double? costPerKg})` updating and returning the row;
    `archiveDose(String id)` and `restoreDose(String id)`, each an update writing a UTC ISO-8601

    string for a blank active ingredient or a blank cost — the column is nullable and a blank string
    would defeat the "omit the row" rendering rule downstream.

    `doseRepositoryProvider` as a plain `Provider<DoseRepository>` built from
    `supabaseServiceProvider`; `doseListByPropertyProvider` as a
    `FutureProvider<List<Dose>>` that awaits `currentPropertyProvider.future`, returns a const empty

    `archivedDoseListByPropertyProvider` as the sibling `FutureProvider<List<Dose>>` passing
