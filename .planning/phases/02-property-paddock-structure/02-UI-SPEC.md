## Spacing Scale

Declared values (multiples of 4 only). Source: observed in Phase 1 screens (`login_screen.dart`, `no_access_screen.dart`).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon gaps, inline label spacing (e.g. arrow_drop_down gap) |
| sm | 8dp | Compact element spacing (TextButton stacking, SnackBar actions) |
| md | 16dp | Default element spacing between form fields, card body padding edge |
| lg | 24dp | Card inner padding, section padding, between icon and heading |
| xl | 32dp | Between major form sections, between heading and card |
| 2xl | 48dp | Top breathing room on full-page forms (SizedBox before logo) |
| 3xl | 64dp | Not used in this phase |

Exceptions:
- Touch targets (FAB, FilledButton): minimum 48dp height — enforced via `minimumSize: Size(double.infinity, 48)` on FilledButton and FAB default 56dp.
- Card border radius: 12dp (not on spacing scale — border-radius token).

## Typography

Material 3 TextTheme. Source: `app_theme.dart` (M3 defaults from seed), confirmed in Phase 1 screens.

| Role | M3 Style | Size | Weight | Line Height | Usage in this phase |
|------|----------|------|--------|-------------|---------------------|
| Body | `bodyMedium` | 14sp | 400 | 1.43 | List item subtitles, field helper text, empty state body |
| Label | `bodyLarge` | 16sp | 400 | 1.5 | List item primary text, popup menu items, form field input text |
| Heading | `titleLarge` | 22sp | 600 | 1.27 | Screen titles, dialog headings, empty state heading |
| AppBar | explicit `fontSize: 18` | 18sp | 400 | — | PropertySelector label in AppBar (existing pattern, Phase 1) |

Rules:
- Do not introduce new font sizes outside this table.
- Weight 400 (regular) and weight 600 (semibold) only — no 500, no 700.
- All text in pt-BR locale. Use `intl` package for numeric formatting (area, capacity).

## Color

Source: `ColorScheme.fromSeed(seedColor: Color(0xFF4A6741), brightness: Brightness.light)`. M3 generates the full scheme — do not hardcode hex values in widgets. Reference roles by `Theme.of(context).colorScheme.*`.

| Role | ColorScheme Token | Usage |
|------|-------------------|-------|
| Dominant (60%) | `colorScheme.surface` | Scaffold background, screen body |
| Secondary (30%) | `colorScheme.surfaceContainer` | Cards, list tile backgrounds, form card |
| Accent (10%) | `colorScheme.primary` | FAB, FilledButton fill, selected NavigationRail destination, active icon |
| Destructive | `colorScheme.error` | Delete confirmation dialogs, error SnackBar, destructive action buttons only |

Accent reserved for:
1. FAB "+" button (create piquete, create propriedade)
2. `FilledButton` primary CTA (form submit: "Salvar", "Criar fazenda")
3. Selected NavigationRail / NavigationBar destination indicator
4. Active icon in NavigationRail (Piquetes destination highlight when on this tab)

Accent is NOT used on: list items, secondary actions, read-only badges, dividers, subtitles.

Additional color rules:
- Muted/secondary text: `colorScheme.onSurface.withValues(alpha: 0.6)` — same pattern as `property_selector.dart` line 69.
- Disabled states: `colorScheme.onSurface.withValues(alpha: 0.38)` (M3 standard).
- Role-based visibility (D-06): edit/delete actions are conditionally absent from the widget tree for non-veterinários — no disabled color state needed for those elements.

## Screen Inventory

### 1. `/propriedades` — Gerenciar Fazendas Screen

**Trigger:** "Gerenciar fazendas" option added to `PropertySelector` PopupMenu (D-10).
**Layout:** Mobile-first `Scaffold` with `AppBar` + `ListView` + `FloatingActionButton`.
**Breakpoint behavior:** Same breakpoint logic as AppShell (600dp) — this screen lives inside the shell via a nested route or modal push from PropertySelector.

**Component structure:**
```
Scaffold
  AppBar(title: Text('Fazendas'))
  body: ListView.builder (propertyList)
    → ListTile per property:
         leading: Icon(Icons.home_work_outlined)
         title: Text(property.nome)           ← bodyLarge / 16sp
         subtitle: Text(property.proprietario) ← bodyMedium / 14sp / muted
         trailing: [veterinário only] PopupMenuButton(edit, delete)
  floatingActionButton: [veterinário only] FloatingActionButton(
    onPressed: → open create dialog/sheet,
    child: Icon(Icons.add),
    tooltip: 'Criar fazenda',
  )
```

**States:**
- Loading: `ListView` shimmer or `Center(CircularProgressIndicator())`
- Empty: empty state widget (see Copywriting)
- Error: `SnackBar` with error copy
- Populated: list with items

**Buttons:**
- `TextButton('Cancelar')` — left/secondary
- `FilledButton('Salvar')` — right/primary; 48dp height; shows `CircularProgressIndicator(strokeWidth: 2, width: 20, height: 20)` when busy

**Validation:**
- `autovalidateMode: AutovalidateMode.onUserInteraction` (Phase 1 pattern)
- Both fields required: error copy "Campo obrigatório"

## Interaction Contracts

### Form submission pattern (all forms)
1. User taps `FilledButton('Salvar')`.
2. Button becomes busy: replace label with `CircularProgressIndicator(strokeWidth: 2)` sized 20×20.
3. On success: dismiss dialog/sheet, list refreshes via Riverpod invalidation.
4. On error: show `SnackBar` with error copy. Button returns to idle.

### Soft-delete (D-11, D-16)
- Tap "Excluir" in PopupMenu → show `AlertDialog` with destructive confirmation (see Copywriting).
- On confirm: set `deleted_at`, record disappears from list on next rebuild.
- No undo/restore in this phase.

### Role visibility (D-06)
- `veterinário`: FAB visible, PopupMenu (edit/delete) on list items visible, AppBar actions on detail screen visible.
- `proprietário` / `leitor`: FAB absent (`floatingActionButton: null`), trailing PopupMenu absent, AppBar actions absent. List is read-only.
- Implementation: wrap with `if (perfil == 'veterinario') ...` — not `Visibility(visible: false)` or `Opacity(0)`.

### Navigation
- PropertySelector dropdown adds item "Gerenciar fazendas" (D-10) → `context.push('/propriedades')`.
- Tapping a piquete list item → `context.push('/piquetes/${id}')` (D-15).
- Back navigation: system back / AppBar back button returns to list.

## Accessibility Contract

- All interactive icons: `tooltip` set (required by Material 3 — no naked `IconButton`).
- `FloatingActionButton`: `tooltip: 'Criar piquete'` / `'Criar fazenda'`.
- `PopupMenuButton`: `tooltip: 'Opções'`.
- Minimum touch target: 48×48dp (enforced by FilledButton `minimumSize`, FAB default, and M3 ListTile height).
- Destructive buttons use `ButtonStyle` with `foregroundColor: colorScheme.error` — never only icon color.
- All form fields have `labelText` (not just `hintText`) for persistent label accessibility.
