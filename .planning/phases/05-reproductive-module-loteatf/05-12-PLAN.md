<objective>
Close **CR-01**, the one blocking gap in `05-VERIFICATION.md` that holds Phase 5 at `gaps_found`.

`register_baixa`'s final `UPDATE animals` sets the animal's general `observation` column with
`COALESCE(p_observation, observation)` — a *replace*, not an append. Any text a vet types into
`BaixaDialog`'s "Observação" field (hint: "Observações adicionais (opcional)" — which promises
additive behavior) silently destroys every prior general note on that animal (health remarks,
body-condition notes). The same statement sets `deleted_at`, so the lost text is unrecoverable
through the UI. Confirmed unpatched at `supabase/migrations/20260805_05_atf_rpcs.sql:310-314`.
