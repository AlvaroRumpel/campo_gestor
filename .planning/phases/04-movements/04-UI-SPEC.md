| Role | Material 3 Role | Weight | Line Height | Usage in Phase 4 |

## Color

All colors come from `ColorScheme.fromSeed(seedColor: Color(0xFF4A6741), brightness: Brightness.light)`. Do not use hard-coded hex values except where already established.

| Role | Source | Usage |
|------|--------|-------|
| Dominant (60%) | `colorScheme.surface` / `colorScheme.background` | Page background, ListView body, Scaffold body |
| Secondary (30%) | `colorScheme.surfaceContainerHighest` | Cards (`AnimalInfoCard`, `_LoteHeaderCard`, all dialog content cards) |
| Accent (10%) | `colorScheme.primary` | Tappable text links (lote name, piquete name in KvRow), filled button background, selected NavigationRail/NavigationBar item |
| Destructive | `colorScheme.error` / `colorScheme.errorContainer` | Baixa button `foregroundColor`, archived animal status badge background — NOT used in Phase 4 (movements are not destructive) |

Accent reserved for:
1. Tappable `InkWell` text links inside KvRow (lot name, paddock name)
2. `FilledButton` (confirm move actions) — background via `colorScheme.primary`
3. `FloatingActionButton` (existing pattern, not added in Phase 4)
4. Active navigation item indicator

Muted text color: `colorScheme.onSurface.withValues(alpha: 0.6)` — used for secondary labels, subtitles, empty state body.

## Dialog Specification

### MoverAnimalDialog

Structure (matches `BaixaDialog` template):

```
AlertDialog(
  title: _saving
    ? LinearProgressIndicator()           ← replaces title text during save
    : Text('Mover animal #N para outro lote?'),
  content: SizedBox(
    width: 480,
    child: SingleChildScrollView(
      child: Column(
        children: [
          Text(explanation, bodyMedium italic),
          SizedBox(height: 16),
          _LotePickerList(                 ← scrollable list of target lots
            items: lots excluding current lot,
            selected: _selectedLotId,
            onChanged: (id) => setState(...),
          ),
        ],
      ),
    ),
  ),
  actions: [
    TextButton('Cancelar'),
    FilledButton('Confirmar movimentação'),  ← disabled until a lot is selected
  ],
)
```

Picker list item layout per D-03 (CONTEXT.md):
- Primary text: lot name — `titleMedium` or `bodyLarge w600`
- Secondary text: `"Piquete [nome] · [N] animais"` — `bodyMedium`, `alpha: 0.6`
- `ListTile` with `selected: id == _selectedLotId`, uses `colorScheme.primaryContainer` for selected background

Picker height: constrained to `maxHeight: 320` via `ConstrainedBox` to avoid oversized dialogs on web.

### MoverLoteDialog

Structure:

```
AlertDialog(
  title: _saving
    ? LinearProgressIndicator()
    : Text('Mover lote "[nome]" para outro piquete?'),
  content: SizedBox(
    width: 480,
    child: SingleChildScrollView(
      child: Column(
        children: [
          Text(
            '[N] animais serão transferidos para o novo piquete.',
            bodyMedium,
          ),
          SizedBox(height: 16),
          _PaddockPickerList(
            items: paddocks excluding current paddock,
            selected: _selectedPaddockId,
            onChanged: (id) => setState(...),
          ),
        ],
      ),
    ),
  ),
  actions: [
    TextButton('Cancelar'),
    FilledButton('Confirmar movimentação'),  ← disabled until a paddock is selected
  ],
)
```

Paddock picker list item layout:
- Primary text: paddock name — `bodyLarge w600`
- Secondary text: area in ha if available — `bodyMedium`, `alpha: 0.6`
- `ListTile` with `selected` highlight using `colorScheme.primaryContainer`

Picker height: same `maxHeight: 320` constraint.

## Interaction Contracts

### Move Animal Flow

1. User taps "Mover animal" in `AnimalInfoCard` (gate: `isActive && canEdit`).
2. `showDialog<bool>` opens `MoverAnimalDialog(animal: animal)`.
3. Dialog loads lot list via `loteListByPropertyProvider(propertyId)` — shows `CircularProgressIndicator` during load.
4. Current lot excluded from picker. User taps a lot item — it becomes selected (`primaryContainer` background).
5. "Confirmar movimentação" enabled only when a lot is selected.
6. On confirm: title replaced with `LinearProgressIndicator`; buttons disabled.
7. On success: dialog pops with `true`; parent invalidates providers per D-11; SnackBar shown.
8. On error: `LinearProgressIndicator` removed; buttons re-enabled; SnackBar error shown; dialog stays open.

### Move Lot Flow

1. User taps "Mover para piquete" in `_LoteHeaderCard` (gate: `lot active && activeCount > 0 && canEdit`).
2. `showDialog<bool>` opens `MoverLoteDialog(lot: lot, activeAnimalCount: N)`.
3. Dialog loads paddock list via `paddockListByPropertyProvider(propertyId)` — shows `CircularProgressIndicator`.
4. Current paddock excluded. User taps a paddock — it becomes selected.
5. "Confirmar movimentação" enabled only when a paddock is selected.
6. On confirm: title replaced with `LinearProgressIndicator`; buttons disabled.
7. On success: dialog pops with `true`; parent invalidates providers per D-12; SnackBar shown.
8. On error: `LinearProgressIndicator` removed; buttons re-enabled; SnackBar error; dialog stays open.

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Touch target minimum 44px | `ListTile` default height satisfies this in picker lists |
| Focus order | Dialog opens with focus on first interactive element (`ListTile`); Tab cycles through picker then action buttons |
| Screen reader labels | `OutlinedButton` text is the label — no additional `Semantics` wrapper needed |
| Disabled state | `onPressed: null` disables button — Flutter renders with `colorScheme.onSurface.withValues(alpha: 0.38)` automatically |
| Loading announcement | `LinearProgressIndicator` in title is visible feedback; no additional `Semantics` needed for MVP |
