# Phase 7 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none — Flutter web app (`useMaterial3: true`), not a shadcn/React/Next/Vite stack. The shadcn init gate does not apply; the design system is Flutter's own Material 3 theme (`lib/core/theme/app_theme.dart`). |
| Component library | Flutter Material 3 built-in widgets — `Card`, `ListTile`, `AlertDialog`, `FilledButton`, `TextFormField`, `DropdownButton`, `Chip`, `FloatingActionButton`, `TabBar`. No third-party UI kit. |
| Icon library | `Icons.*` (Material Symbols bundled with Flutter SDK) — every prior phase (0–6) uses this exclusively; `flutter_svg` is in the stack but unused for icons. |
| Font | Platform default (Roboto on web/Android, San Francisco fallback on iOS/macOS) — no `fonts:` block in `pubspec.yaml`, no `google_fonts` (explicitly disallowed by CLAUDE.md "What NOT to Use"). Phase 7 introduces no font. |

**ColorScheme source:** `ColorScheme.fromSeed(seedColor: Color(0xFF4A6741), brightness: Brightness.light)` — a moss-green/agrarian seed (D-12, Phase 0). Dark mode is deferred project-wide; Phase 7 does not add it.

## Typography

Material 3's default `TextTheme` is used unmodified (`app_theme.dart` sets no `textTheme:` override) — sizes below are Material 3 role defaults, not custom pixel values. Two weight tokens are declared, matching the exact idiom already repeated in every prior phase (never a third ad-hoc weight):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14sp (`bodyMedium`) | Regular (400) | 1.43 |
| Label | 16sp (`bodyLarge`, `.copyWith(fontWeight: FontWeight.w600)`) | Emphasis (600) | 1.5 |
| Heading | 16sp (`titleMedium`) | Medium (500) | 1.5 |
| Display | not used this phase | — | — |

Usage mapping for this phase:
- **Body** (`bodyMedium`, regular): secondary/subtitle text — expense description, dimmed metadata line (`onSurface.withValues(alpha: 0.6)`, same as `_AplicacaoCard.subtitle` / `_DoseCard` ingredient line).
- **Label** (`bodyLarge` + w600 override): card primary text — category name on an expense row, dose name on a sanitary row. Exact idiom already used by `_AplicacaoCard`/`_DoseCard` (`theme.textTheme.bodyLarge?.copyWith(fontWeight: FontWeight.w600)`) — do not invent a new override.
- **Heading** (`titleMedium`): AppBar title ("Gastos — {piquete}"), empty-state heading, dialog title ("Novo gasto" / "Editar gasto"), section header ("Gastos" card title on `PaddockDetailScreen`).
- Computed/highlighted numeric text (the total in R$) uses `bodyMedium`/`bodyLarge` tinted `colorScheme.primary` — same "computed field" idiom as the per-UA figures in `dose_form_dialog.dart`/`sanitario_screen.dart` (never a distinct type size for emphasis, only a color shift).

## Color

Values are Material 3 **role names**, not fixed hex — `ColorScheme.fromSeed` generates the actual hex per role and this project has no dark theme, so role names are the stable contract.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `colorScheme.surface` | Scaffold background, screen body |
| Secondary (30%) | `colorScheme.surfaceContainerHighest` / `surfaceContainerHigh` | Expense cards, sanitary-row cards (`_AplicacaoCard` reuses `surfaceContainerHighest`), status badges (`surfaceContainerHigh`) |
| Accent (10%) | `colorScheme.primary` | FAB background ("Novo gasto"), computed total figures, filter chip/preset selected state, `TextButton` navigation links (e.g. tap-through to `/aplicacoes/:id`) |
| Destructive | `colorScheme.error` (+ `onError`) | "Excluir" button background in the delete-confirmation `AlertDialog` (D-28), inline form/list error text |

Accent reserved for: FAB background icon, the R$/count total figure at the top of the list, the "N lançamento(s)" computed count text, filter-preset chip selected fill, and text-button navigation affordances (e.g. a "Ver aplicação" link from an error state, mirroring `EstornarAplicacaoDialog`'s "Ver estorno"). Never applied to plain body text, card titles, or category icons (category icons render in `onSurface`/default icon color, matching `Icons.fence` on `_PaddockCard` — no per-category color per D-05).
