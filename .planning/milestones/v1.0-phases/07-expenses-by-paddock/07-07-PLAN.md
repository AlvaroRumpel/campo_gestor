| Boundary | Description |
|----------|-------------|
| async fetch failure → displayed financial figure | An error path that degrades to a formatted number is indistinguishable from real data |
| two role predicates on one screen | A single screen now expresses two different authorization intents; conflating them silently changes who can do what |
