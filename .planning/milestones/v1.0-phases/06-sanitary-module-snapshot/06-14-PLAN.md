<objective>
Send the per-animal sanitary history containment filter as JSON instead of as a Dart List, and stop
Riverpod from hiding deterministic backend errors behind a spinner.

Purpose: G-06-9, a blocker. `fetchSanitaryHistoryByAnimal` passes a Dart List to `.contains()`.
postgrest-dart 2.7.0 encodes a List as a Postgres array literal and stringifies each element with
Map.toString, so the request carries `composition_snapshot=cs.{"{animal_id: <uuid>}"}`. Postgres
parses that as JSON, hits a closing brace where a colon is required, and answers 22P02. Riverpod 3's
default retry then re-issues the same deterministic failure about ten times, so the section never
reaches its error branch and the user sees a permanent spinner.
Output: a one-line encoding fix with a request-level regression test, and an app-wide retry policy
that lets a PostgREST error render as an error.
</objective>
