<objective>
Close the two AtfDetailScreen rendering/gating gaps from 05-UAT.md test 3. Both are client-side
Dart defects; no migration, no RPC change, no database work.

- **G-05-2 (major):** after a baixa, "Registrar DG" still lists the baixa'd animal as an editable
  row with its old chip selected. This is NOT a stale cache — 05-11 already invalidates every
  provider involved and the data is verified fresh. It is a documented design conflation:
  `animal_atf_memberships.active = false` means both "the ATF was closed" and "the animal was
  baixa'd", with no signal distinguishing them, and `_DgSection` renders every row unfiltered on
  purpose so D-16 correction keeps working. The user chose the UI-only fix: give the Dart layer the
  missing signal and hide only the baixa'd rows.
- **G-05-3 (major):** the encerrar banner appeared on an ATF where 0 of 5 animals had any DG, while
  its own confirm dialog correctly said "Ainda há 5 animais sem DG registrado." The banner gates on
  `summarizeDg(...).pending`, whose `total` counts every animal that EVER had a DG for this ATF
  (D-20, correct for the % header) — reused as a live "does every CURRENT member have a DG" check
  it is simply the wrong question. When composition churns, the historical total reaches the new
  composition count and clamps `pending` to 0.

Purpose: two contradictory surfaces on the same screen — a list showing an animal that is gone, and
a banner inviting an encerramento the dialog behind it refuses to endorse.
Output: one new model field fed by one new selected column, one row filter, one hoisted set with
four consumers, and regression tests that fail if any of it is reverted.

**Explicitly out of scope, by user decision (2026-08-05):** `dg_summary.dart`. `summarizeDg`'s
D-20 historical-total behaviour is correct for the % prenhez header and must not change. Both gaps
were diagnosed as misuse of that function elsewhere, not as a defect inside it. Do not "fix" the
percentage math — it was verified byte-identical pre- and post-baixa and is behaving as designed.
</objective>
