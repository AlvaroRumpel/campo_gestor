<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL path parameter → provider family key | `atfId` comes from the address bar and is attacker-controllable on web |
| Rendered data → the veterinarian's clinical decision | A wrong or stale percentage is acted upon in the field; correctness here is a safety property, not cosmetics |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-20 | Information Disclosure | Navigating to `/atf/<id>` for an ATF in a property the user is not a member of | high | mitigate | `members_can_read_atf_batches` (05-01) makes the SELECT return no row; the screen renders the error state and no header, never partial data from another tenant |
| T-05-21 | Spoofing | A guessed or pasted `atfId` used to enumerate other properties' ATFs | medium | mitigate | Same RLS SELECT policy; the id is a `gen_random_uuid()` value, so enumeration is not feasible and a hit still returns nothing |
| T-05-22 | Tampering | The header showing a percentage that disagrees with the ATF card on the list screen | low | mitigate | Both call `summarizeDg`/`formatPrenhez` from `dg_summary.dart`; this plan's acceptance criteria forbid local percentage arithmetic |
| T-05-23 | Information Disclosure | The bull row deep-linking to an animal in another property | low | mitigate | `bull_animal_id` is a FK to `animals` and the `atf_batches_bull_required` path is filled only from the property's own touro list (plan 05-05); the target route is itself RLS-guarded |
</threat_model>
