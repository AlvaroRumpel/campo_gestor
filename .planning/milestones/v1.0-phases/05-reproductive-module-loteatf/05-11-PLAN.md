<objective>
Close the two gaps diagnosed in 05-UAT.md test 1. Both are client-side Dart defects — the
database side of D-19 is already correct after `20260806_05_fix_atf_membership_trigger_scope`.

- **G-05-1 (blocker):** `register_baixa` does deactivate the ATF membership server-side, but
  `BaixaDialog._submit()` never invalidates the reproducao feature's three ATF-composition
  providers. They are plain (non-autoDispose) FutureProviders, so the ATF detail screen keeps
  serving the pre-baixa composition from cache until the app restarts. The animal correctly
  disappears from animais/lotes (those providers *are* invalidated) while appearing to still sit
  in the ATF — which is what the user reported.
- **G-05-1-nav (minor):** `/atf/:atfId` is a root-level GoRoute reached via `context.go(...)`,
  which replaces the nav stack, so `Navigator.canPop()` is false on arrival and Material's default
  AppBar renders no back arrow. `atf_detail_screen.dart`'s header comment claims to mirror
  `lote_detail_screen.dart` but the explicit `leading:` was never copied.

Purpose: unblock 05-UAT.md tests 2, 3 and 4, all of which are gated on test 1.
Output: two production files fixed, two widget test files extended with regression coverage.
